# THE REAL PRICE

An interactive systems exhibit about the costs hidden behind an ordinary purchase. The experience follows a product through labor, time, logistics, ownership, waste, and broader structural pressures instead of treating the checkout price as the whole story.

## Live

https://wizzardpig-stack.github.io/The-REAL-price/

## What it demonstrates

- Long-form interactive storytelling combined with calculators and evidence sections
- Responsive object selection and journey layouts
- Mobile-specific composition at 900px and 620px breakpoints
- Use of small viewport units for phone-height stability
- Static deployment with no backend requirement

## Stack

HTML, CSS, vanilla JavaScript, SVG and browser-native interaction.

## Development approach

Independent product concept, research framing, interaction design, iteration, QA, and AI-assisted implementation. The project is built as an explorable exhibit rather than a conventional dashboard.
